# noxapp.github.io

Site de présentation de **Nox**, le compagnon de bureau pour les cerveaux TDAH.

- Site : https://noxapp.github.io
- Code de l'application : https://github.com/adebayo-moutalabi/nox
- Télécharger : https://github.com/adebayo-moutalabi/nox/releases/latest

## Mettre à jour

- **La page** : `index.html` (copie de `docs/index.html` du dépôt du projet).
- **La vidéo** : dépose-la sous `video/nox-demo.mp4`, fais un commit et pousse. Elle s'affiche automatiquement à la place de « La vidéo arrive très bientôt ».
- **Les images** : `linkedin/` (captures de l'appli) et `assets/` (icône, polices, couleurs).

Polices Nunito et Inter : SIL Open Font License 1.1 (`assets/fonts/`).
